# Проекты

Здесь собраны несколько учебных проектов, над которыми я работала в рамках курса. Каждый из них посвящён отдельному этапу работы с приложением — от контейнеризации до автоматизации и мониторинга.

---

## Docker-приложение

Первый проект был посвящён основам контейнеризации. Я познакомилась с Docker, научилась работать с образами и контейнерами, запускать веб-сервер и использовать volumes для хранения данных.

**Что использовала:**

- Docker
- Ubuntu
- nginx
- Docker volumes

[Посмотреть проект на GitHub](https://github.com/marylampadova23-art/devops-lab-lampadova)

---

## CI/CD для Docker-приложения

Во втором проекте я настроила автоматический pipeline в GitHub Actions. После push в ветку `main` Docker-образ автоматически собирается и публикуется в Docker Hub.

Для авторизации использовались GitHub Secrets, поэтому данные для доступа не хранятся непосредственно в коде.

**Что использовала:**

- Docker
- Flask
- GitHub Actions
- Docker Hub
- CI/CD

[Посмотреть проект на GitHub](https://github.com/marylampadova23-art/devops-lab2-lampadova)

---

## Мониторинг с Prometheus и Grafana

Третий проект посвящён мониторингу. Node Exporter собирает системные метрики, Prometheus хранит их, а Grafana используется для визуализации.

В результате был создан дашборд с показателями CPU, памяти и дискового пространства.

**Что использовала:**

- Node Exporter
- Prometheus
- Grafana
- Docker
- системные метрики

[Посмотреть проект на GitHub](https://github.com/marylampadova23-art/devops-lab3-lampadova)

---

Эти проекты помогли мне увидеть, как отдельные инструменты соединяются в один процесс: приложение можно собрать, автоматизировать его публикацию, а затем наблюдать за его работой.
